We’ll now be looking into encodings, and no encodings are not the same as encryptions or ciphers. A cipher hides a message by using a key(s) like an alphabet or a password. And an encoding changes how the message is formatted. An example of an encoding is binary, aka base 2. Binary transforms the characters in the message into base 2, meaning it only uses 2 characters 0 and 1. Encodings are usually made for computers to read data but are also commonly found in decoding puzzles.
