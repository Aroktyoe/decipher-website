Now let’s see if you can identify if this is regular base64 or AES only by analyzing the ciphertext! For this you’ll need to know about ⭐entropy⭐ which is a scale of how random something is. For example AAAAAAAA isn’t very random, but PAIBEMQLIZD is quite a bit more random. We use this to identify if base64 is actually AES or some other modern cipher and not regular base64 because modern ciphers like AES have super high entropy (randomness). If the entropy is close to 7-8, it’s likely AES (8 is max), otherwise it’s probably normal base64. Make sure to analyze the DATA and not the base64 symbols themselves, by decoding it as base64 and THEN getting the entropy, you can use Cyberchef for this.
